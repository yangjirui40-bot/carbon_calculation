# 碳速算企业碳核算平台数据库设计说明

设计审阅稿 · 2026 年 11 月 20 日
线上基线为 PostgreSQL 18.3 的 33 张表。随附 ERD 的目标模型有 104 张逻辑实体表，其中 97 张支撑企业业务与共享配置，7 张属于分析集市。业务扩展按优先链路、现场数据和外部接口条件分批交付。

## 一、服务对象与计划书覆盖

平台服务电子信息制造企业，适用范围从单体工厂到多法人、多场地盘查。财务、生产、采购和工程分别提供原始业务数据。盘查负责人组织核算，复核人关账。管理层根据排放、预算与投资效果决策。供应商报送协同数据，审计员及获授权的核证机构和银行查阅证据。

## 二、数据规则与物理实现约束

### 2.1 账套、人员和组织

- 企业所有业务表包含非空 tenant_id，并加 UNIQUE(tenant_id, id)。企业内对象用 (tenant_id, 引用 ID) 建复合外键。计量单位、GWP 等平台字典经授权共享。
- 应用数据库角色使用 RLS 隔离账套，同时以复合外键防止错误的数据引用。供应商、审计、对外核证另按被授权对象和期限核验。双边配额按两方有效账户与授权核对。
- 角色授权从账套到法人、场地或组织单元，三个可选范围至多填一个。过期或撤销保留历史。法人、场地、部门的企业内编码唯一，组织层级校验同一账套、同一场地和无循环。
- 盘查边界发布后保留版本及合并方法。法人及场地用边界成员表明确纳入或排除，股权法才使用合并比例。期间以账套、边界、粒度及起止日期唯一。经办人、负责人和复核岗位独立授权。

### 2.2 接入、原件、活动及质量

- data_connections 记录凭据引用。raw_objects 记录存储键、哈希、分类和保留期。原件下载及对外传递受授权和日志控制。
- 导入批次按账套、来源连接、请求键幂等。外部业务键在对应来源内唯一，同键不同内容进入异常或新修订。暂存活动按批次与行键定位，保留失败行和错误字段。
- 允许一张单据支持多笔活动，一笔活动也可有多张证据。activity_evidence 的凭证与对象外键恰好选择一个。页面按凭证和页码唯一。识别候选、人工复核和外部验真分别留存，失败仍有状态和来源记录。
- 活动记录有企业内编号、期间、分类和场地。活动修订按活动 ID 与修订号唯一，当前有效版由部分唯一索引约束。结算和报告引用当时修订，后续补录或更正保存新版本。
- 证书按发行方和证号唯一，绑定适用区域、发电时段、注销证明与业务。确认分配时在同一事务锁定证书并核对累计使用量。选择符合适用方法的凭证，地域法和市场法分别留存。

### 2.3 因子、价格、气体及计算

- factor_versions 按因子和版本号唯一。发布后固定单位、来源、地区、气体和价格年份。适用区间与因子组合做歧义检查。分气体计算引用 GWP 版本。已合并因子保存 CO₂e 值与覆盖口径。
- 投入产出数据版本冻结矩阵、气体清单、币种、价格年和进口边界。部门逐行映射并保留权重、基准和验收人。派生运行引用价格调整版本和行业映射版本，保留 CEADs 国内生产与 2017 年价格范围。映射与估算由业务复核。
- 金额建议 numeric(20,4)，排放、系数及活动量 numeric(28,10)，份额 numeric(12,8)。记录单位及期次后，再执行换算与数值校验。
- 核算运行按类型要求期间、PCF 研究或投入产出派生来源。生成编号、创建时间和作业记录可联查。活动修订与 PCF 清单项在同一输入至多选一种，研究输入保留不可变快照。结果行与输入必须归属同一次运行。范围覆盖按运行和类别唯一，区分实际零值、缺项、排除及不适用。双口径电力结果使用不同 basis，聚合时选择其中一套。
- 正式训练运行保存基座、训练集与验证集对象、训练版本、参数和检查点摘要。评估保存划分摘要、覆盖和实际训练标记。平台模型发布是一项授权操作，训练数据与评估对象保留账套访问边界。规则、OCR、纠偏模型、SER 和图传播估算各记录运行状态。

### 2.4 关账、核证与证据

- 关账版按期间和修订号唯一。版本引用对应期间、边界和运行快照。提交前清理待确认活动、未判定范围和重大质量工单，固定来源报告。关账、退回、重开等动作记录版本、处理人、原因和时间。
- 送审与复核由不同企业成员执行。批准时同时校验状态、版本及授权期。重开后进入下一版，历史报告保持原快照和审批。
- 发行报告按账套、编号与发行号唯一。组织/产品报告绑定对应核算运行，供应商披露报告绑定披露计划。关账清单须绑定匹配的关账版。按发行版、格式、语言和交换规范管理 PDF、XML、工作簿等附件。
- 审计记录追加写入，核验证据摘要和前序摘要可回放。内部完整性回执、外部可信存证与第三方核证结论分别记录。银行等查看权限有授予方、对象和有效期。绿色金融评估稿记录指标口径、权重及证据。金融机构须验证指标体系及结论后方可采信。

### 2.5 产品、供应链、减排和配额

- BOM 父子明细必须属于同一 BOM 版本，禁止环和自指。研究关联同一产品版本的 BOM。声明单位、参考期、生产量、数据类型和方法版本随研究固定。生产活动分摊按期间、依据及用途核对总量。
- 供应链关系下游可选企业法人或供应商，两者恰好填一个，并校验上游、下游及账套归属。按报告时点回放网络。披露请求按计划、供应商和范围唯一。报送人只能访问生效授权对应的供应商。
- 供应商报送总量或强度保留单位、参考期、边界与数据来源。实际报送、邻接估算、缺失在风险快照中分别保留。汇总时检查重叠组织边界及重复纳入。
- 年度预算按边界、年份和版本唯一，分解总量校验。情景冻结基线运行、措施、预测期限、折现率和币种。按月份保存照常营业线、干预线与现金流。实绩用核算快照或凭证证实，形成减排效果跟踪。
- 内部配额支持同一账套与授权企业间转移。双方复合外键分别匹配各自企业和账户，同年度、余额充分及独立接受权限均满足时才写入两侧流水。每笔转移恰有两条数量相反的分录，并以请求键防重。参考价格单独保存。真实市场交易及清结算按外部对接验收。

### 2.6 查询、分析和迁移风险

- 高频查询复合索引以账套开头，覆盖组织、月份、来源号、状态及快照。按实际增长量决定分区。企业试点验收包含并发写入、执行计划、恢复与权限回归。
- 明细事实按刷新版本、结果行和核算口径保存。汇总事实按已关账快照、法人、期间和口径保存。驾驶舱的趋势、热力、桑基图和下钻使用一致的刷新版本。
- 原 33 张表按附录 A 全量映射。缺少真实厂区、模型指标、历史排放证据及核证结果的数据保留缺失说明，由业务补证。以已上线核算期间、金额、报告版本和原文件哈希作为差异对账依据。
