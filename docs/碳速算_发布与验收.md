# 碳速算企业平台发布与验收

2026-11-20 发布的 Docker 镜像为 `carbonspeed-backend:20261120-enterprise-domains-r1`。公网 https://carbon.yjr-adc-demo.xyz/login ，本机 http://127.0.0.1:18083/ 。

## 数据库变更结果

生产迁移从 81 张增至 121 张。104 个设计表名与数据库逐名一致，57 张表启用行级安全。上线前同主机恢复历史数据库并连续初始化两次，原有 5775 条活动和 8 份报告均有对应的业务主键。上线后独立恢复备份，复查 121 张表、5861 条活动、54 次核算和 10 份报告。演练覆盖同主机备份恢复，尚未演练跨地域故障切换。

## 物理字段核对

生产库共有 996 列、286 个外键约束、294 个索引。设计清单显式列出 656 个业务字段，340 个在对应生产表中完全同名，对其余 316 个已注明 74 个异名字段的具体承载方式和限制，另有 242 个尚未逐项证明语义等价。不能把实体名称全部对应解释为全部字段、细粒度授权或业务验收均已完成。逐表差异见《线上数据库字段与约束.xlsx》。

## 如何复查

1. 打开本目录「模拟企业体验账号_仅本机.txt」，按角色登录；录入与审计采用不同账号。
2. 在「工厂计量与预算」核对三个电表和两个月度的预算。九月已关账，十月可继续操作。独立模拟企业共有 86 条活动记录。
3. 在「报告中心」进入九月组织报告，查看营收、排放和每万元营收强度。管理员可为已登记的接收机构导出固定版本的材料；审计员可查看。
4. 要查看版本的十个月历史和十二个月预测，可在模拟企业的减排模拟器选择「两厂节电改造」。
5. 需要定位表时打开「ERD数据库实施对照.md」。精确的生产表名、行数抽点、浏览器检查项目和版本校验值在「实测结果.json」。

## 营收证明权限验收

在独立测试账套和公网指定模拟企业核对财务原件。企业管理员可上传及预览，同企业审计员可只读查看，普通经办人的单据列表隐藏收入底稿且不能预览、查看处理历史或上传该类证明。普通票据仍走原业务流程。

## 企业推广前仍需外部验收的事项

- 企业自有中文票据 SER 尚无获授权的目标样本、实训权重及独立测试成绩。训练入口现可登记训练集、验证集和权重哈希；生产 SER 保持关闭。真实 OCR 与大模型推理为另一条已接通路径。
- 发票验真需授权服务，核证意见、银行授信或交易所成交需对方真实受理。系统已可准备、限制导出并核验交付文件。
- 行业价格指数、全生命周期活动、合同电力因子及剩余电力组合须按企业实际边界与来源录入。已验证采购与部分生产活动，完整生命周期认证、外部交易及银行回执尚未验收。
- 单台部署暂未形成多可用区 HA、异地灾备或企业级 SLA。批量回归覆盖十万行导入，实际客户并发吞吐与恢复时限仍须专项验收。模拟数据仅供演练。
