# 因子数据来源与核算边界

## 1. 官方公告与派生值

- 2022年全国电力平均二氧化碳因子：0.5366 kgCO₂/kWh；华中0.5395、湖南0.4900。来源：https://www.mee.gov.cn/xxgk2018/xxgk/xxgk01/202412/t20241226_1099413.html 。不应把全国平均值与剔除市场化交易非化石电量的0.5856混用。
- 2024年全国电力碳足迹因子：0.5777 kgCO₂e/kWh。属于生命周期电力碳足迹口径，不与企业Scope2直接用电因子直接互换。来源：https://www.mee.gov.cn/ywdt/zbft/202510/t20251024_1130763.shtml 。
- 柴油2.60为所列热值、含碳量、氧化率和密度参数推导的燃烧CO₂估计；不是所有地区与燃料批次通用的实测值，不覆盖CH₄/N₂O。

## 2. CEADs研究系数

- 作者公开清单：Shan等，China national CO2 emission inventory (sectoral approach), 2016–2017，https://doi.org/10.6084/m9.figshare.9784370 ，CC BY 4.0。原始文件可从上述 DOI 获取；本机原件为 data/io/CEADs_national_2016_2017.xlsm，不随源码仓库分发；仅解析缓存数值，未运行宏。
- 原清单单位为Mt CO₂。提取2017年生产部门，排除城镇、农村居民直接排放；与42部门投入产出目录对应后，用排放kg/总产出万元求直接强度g，再以f=g(I−A)⁻¹求完全强度，除以10000转为kgCO₂/CNY。
- 运输通信、商贸餐饮及其他服务的合并项无法从原始数据直接观察42部门分项，采用总产出比例分配。详细份额、分配前后数值在ceads_2017_crosswalk.csv；这属于研究假设，并非官方42部门清单。生产部门总量8893.57 Mt CO₂；分配前后守恒。
- 对应投入产出表由CEADs31省42部门MRIO聚合而来：https://doi.org/10.5281/zenodo.4569117 。来源不是独立发布的官方全国基本流量表。源文件中的进口列为未提供，不代表中国进口为零；默认计算覆盖国内生产联系。
- 生成因子只适用于Scope3购买商品与服务的金额法研究估算；不替换Scope1燃料燃烧或Scope2用电因子，不覆盖Scope3全部15类。
- g_2017.metadata.json保存气体覆盖、价格年度、来源、原文件与映射哈希。原字段名kgco2e_per_wan为兼容旧接口保留，实际气体覆盖仅CO₂（GWP=1），不能因此声称完整温室气体盘查。

## 3. 使用限制

2017年生产者价格与当前含税采购支付金额不可直接等同。正式核算需明确未税口径、价格年度/平减指数、贸易运输边际及进口产品适用模型；本平台研究因子未自动完成这些校正，相关结果必须复核。因子不确定性暂无来源数据时显示未提供；10%情景参数与独立误差正态近似均不是第三方验证的置信区间。

演示因子和演示业务保留明确标签，不作为企业合规依据。平台报告为核算输出及审阅材料，不替代第三方核证、CBAM申报认证或法定配额交易。平台内配额流转是内部管理台账，未连接碳市场或付款结算渠道。
