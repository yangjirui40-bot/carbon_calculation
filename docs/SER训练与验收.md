# 中文票据SER训练与验收

本平台的SER是文档语义实体识别，不是语音情绪识别。当前没有自有中文票据标注集，不声明已经取得目标企业票据的准确率。

1. 在独立GPU训练环境安装运行依赖以及 `accelerate`、`seqeval`。不要在现有2GB云服务器训练。
2. 准备独立的 `zh_train.json`、`zh_val.json`，顶层 `documents`；每项含 `img: {fname: 相对图像路径}` 和 `document` 实体数组。实体含 `text`、像素坐标 `box: [左,上,右,下]`、`label`（question/answer/header/other），可附 `words` 数组。图像放数据根目录对应路径。
3. 使用发票模板、供应商、日期分组切分训练/验证；同一票据及重复截图不得跨集合。公开XFUND中文表单可用于流程验证，不能代替企业票据测试集。应核对模型及数据使用许可。
4. 执行 `python -m app.services.ai.train_ser --data 数据根目录 --out models/ser_zh`。脚本对像素框归一化、按词窗口处理长文档、由处理器对齐子词标签，并检查图像哈希泄漏。
5. 查看输出 `evaluation.json`，核对实体级precision/recall/F1、文档数、窗口数、标注文件哈希和是否执行训练。另行统计金额、税额、数量、单位和企业标识等字段的精确匹配率；不得只报token accuracy。
6. 将模型配置、权重、处理器完整目录部署到模型卷；填写 `SER_MODEL=/app/models_cache/ser_zh`、`SER_ENABLED=true`，重启碳平台后端。模型加载失败继续规则抽取，必须保持人工复核。
7. 用目标企业独立测试集比较规则、SER及组合路径，记录识别覆盖率、错误金额、人工修订率、耗时和失败样本。未完成该验收时不自动确认票据。

公开模型基准是公开表单任务的实验结果；平台没有企业标注数据时保留OCR＋规则＋人工复核路径。高置信度不等于单据真实，发票查验服务尚未配置时必须显示“未查验”。
