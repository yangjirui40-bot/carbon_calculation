# 碳速算 ERD 实施对照

生产 PostgreSQL public 架构逐名查询。设计 104 项全部同名建表，另保留 17 张业务兼容表，共 121 张。行级安全已启用 57 张。原设计中的字段命名、身份迁移与扩展权限仍须按实际实现判断。

字段可在「线上数据库字段与约束.xlsx」查阅。656 个显式业务字段中有 340 个同名，另核对了 74 个不同名字段的承载位置与粒度，其余 242 个仍需结合业务语义验收。
列中行数是本次抽点时的生产计数，空白表示本次未对该表计数。零笔表示尚无相应记录。
