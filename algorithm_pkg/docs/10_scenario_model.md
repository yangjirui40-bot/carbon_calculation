# 第四阶段：减排路径情景模拟模型 v0.1

## 1. 业务依据与边界

根据现有业务分类与演示数据：
- 基准核算编号：run-001
- 情景 sc001：节电 10%
- 情景 sc002：节电 15% + 采购减少 5%

模拟器读取企业既有核算记录，生成副本，不覆盖基准记录。只调整已确认记录：
- Scope 1：柴油耗用量不变；
- Scope 2：电力活动量按节电比例调整；
- Scope 3：采购金额按采购减少比例调整。

## 2. 数学模型

设基准用电量为 \(Q_e\)，节电比例为 \(r_e\)：

\[
Q'_e=Q_e(1-r_e)
\]

设基准采购金额为 \(A_j\)，采购减少比例为 \(r_p\)：

\[
A'_j=A_j(1-r_p)
\]

然后调用既有核算引擎重新计算：

\[
E'_{total}=E'_{S1}+E'_{S2}+E'_{S3}
\]

减排量与减排率：

\[
\Delta E=E_{baseline}-E_{scenario}
\]

\[
R=\frac{\Delta E}{E_{baseline}}\times100\%
\]

## 3. 手算验算

基准：
- Scope 1 = 40 × 2.68 = 107.2
- Scope 2 = 1,200 × 0.58 = 696
- Scope 3 = 10,000 × 0.35 = 3,500
- 合计 = 4,303.2 kgCO2e

情景 sc001（节电10%）：
- 新用电量 = 1,200 × 0.90 = 1,080 kWh
- Scope 2 = 1,080 × 0.58 = 626.4
- 总量 = 107.2 + 626.4 + 3,500 = 4,233.6
- 减排量 = 69.6 kgCO2e

情景 sc002（节电15%＋采购减少5%）：
- 新用电量 = 1,200 × 0.85 = 1,020 kWh
- Scope 2 = 1,020 × 0.58 = 591.6
- 新采购额 = 10,000 × 0.95 = 9,500 CNY
- Scope 3 = 9,500 × 0.35 = 3,325
- 总量 = 107.2 + 591.6 + 3,325 = 4,023.8
- 减排量 = 279.4 kgCO2e

## 4. 计算规则与异常处理

1. 节电比例、采购减少比例必须位于 [0,1]。
2. 必须有有效基准业务记录。
3. 只对已确认记录进行情景调整。
4. 不修改原始业务记录；每次情景计算生成独立结果。
5. 多情景对比必须引用同一基准核算结果。
6. Scope 1 在当前两类情景中保持不变。
7. 产品 PCF 是独立核算对象，不自动并入企业减排情景总账。

## 5. 当前限制

情景仅反映活动量/采购金额按比例变化后的静态排放估算，不包含产量变化、替代效应、供应商结构变化、技术改造成本、反弹效应及时间动态。参数为模拟设定，不代表企业真实减排承诺或实际减排量。
