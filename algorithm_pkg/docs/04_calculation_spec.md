# 第一阶段计算模型说明书（v0.1）

## 1. 范围

本版本实现 Scope 1、Scope 2、Scope 3 采购商品与服务金额法基础计算。EIO-LCA 矩阵推导、产品 BOM、减排情景模拟属于后续阶段，不在本版本计算函数范围内。

## 2. 数据口径

- Scope 1：设备柴油实际耗用量（L）× 柴油排放因子（kgCO2e/L）。
- Scope 2：外购电量（kWh）× 电力排放因子（kgCO2e/kWh）。
- Scope 3：人民币未税采购金额（CNY）× 类别排放强度（kgCO2e/CNY）。
- 仅 `review_status=confirmed` 的记录参与计算。
- 电费仅作为 Scope 2，不重复计入 Scope 3 普通采购。
- 因子值均标记为项目演示设定 `demo-v1`，不代表官方或实测因子。

## 3. 数学表达

\[
E_{S1}=\sum_{i\in S1}Q_i EF_i
\]

\[
E_{S2}=\sum_{i\in S2}Q_i EF_i
\]

\[
E_{S3}=\sum_{j\in S3}A_j EF_j
\]

\[
E_{total}=E_{S1}+E_{S2}+E_{S3}
\]

## 4. 输入校验

1. 数量和金额必须为非负数值。
2. Scope 与 category 必须匹配。
3. factor_id 必须存在，且因子 category 与业务 category 一致。
4. 活动量单位必须与因子量纲一致。
5. Scope 3 首版只支持 CNY 未税采购金额。
6. 未确认记录排除并记录 warning；已确认记录存在错误则终止本次计算，避免输出不完整总量。

## 5. 当前演示基准

- 柴油：40 L × 2.68 = 107.2 kgCO2e。
- 电力：1,200 kWh × 0.58 = 696 kgCO2e。
- 电子元器件采购：10,000 CNY × 0.35 = 3,500 kgCO2e。
- 企业合计：4,303.2 kgCO2e。

## 6. 限制

本版本为模拟数据教学/演示计算，不构成企业温室气体盘查或审计结论。Scope 3 仅覆盖采购商品与服务中的演示类别。因子需在后续实证阶段核验来源、年份、地区、价格基期与边界。
