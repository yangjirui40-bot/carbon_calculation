# IO与CEADs采购研究因子

本仓库附带运行所需的42部门聚合表、部门映射、直接强度向量及溯源元数据。作者原始清单须从下述 DOI 下载；不能把排放总量文件直接改名为 g_2017.csv。

| 文件 | 内容 |
|---|---|
| io2017_42sector.csv | CEADs 31省×42部门MRIO聚合后的全国联系矩阵，金额万元 |
| CEADs_national_2016_2017.xlsm | 作者公开的2016—2017部门CO₂清单；按 DOI 下载，不随仓库分发；本机解析时未执行宏 |
| ceads_2017_crosswalk.csv | 45生产部门到42部门的对应与部分总产出比例拆分 |
| g_2017.csv | 排放kg除以2017总产出万元后的直接强度向量，42行 |
| g_2017.metadata.json | 来源、年份、CO₂口径、价格基础与文件SHA-256 |

研究清单：https://doi.org/10.6084/m9.figshare.9784370 ；MRIO：https://doi.org/10.5281/zenodo.4569117 。许可与完整使用限制见 [因子数据来源与核算边界](../../docs/因子数据来源与核算边界.md)。

引擎计算A[i,j]=Z[i,j]/X[j]与f=g(I−A)⁻¹；元数据匹配后按需要生成三类采购研究因子。CNY采购金额先与万元口径对齐，因子转为kgCO₂/CNY。

管理员在登录后调用POST /api/v1/factors/derive-from-io，已在正式云端完成一次。生成版本research-eiolca-2017，编号CEADS_EEIO_前缀；不得称为官方Scope3发布因子，不覆盖柴油、电力因子。

现有源表没有提供有效进口拆分，不能把占位零当作零进口的观测；2017生产价格、当前含税金额与CO₂e口径不可直接互换。旧字段kgco2e_per_wan仅作兼容名称，实际气体覆盖CO₂。粗行业拆分采用明确的研究分配方法，不是官方42部门观测清单。变更数据时须同步重算向量、映射和元数据哈希，不能只修改文件名。
