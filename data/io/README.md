# 真实投入产出表数据接入说明

## 数据来源（按优先级）

1. **国家统计局《中国投入产出表（2017）》42 部门基本流量表**
   官网渠道：国家统计局官网 → 统计数据 → 投入产出表（需下载 Excel 原表）。
2. **CEADs（中国碳核算数据库）2017 年多区域投入产出表（已定位，可直接下载）**
   - Zenodo 记录（CC-BY-4.0 开放许可）：https://doi.org/10.5281/zenodo.4569117
   - 2017 文件直接链接（浏览器打开即下载，约 48.9 MB）：
     `https://zenodo.org/records/4569117/files/MRIO2017_42+CEADS.xlsx?download=1`
   - 下载后放入本目录 `downloads/`，运行 `python _build_io_from_xlsx.py` 即自动
     解析 31 省×42 部门 MRIO、各省求和构建全国 42 部门表并写入 `io2017_42sector.csv`。
   - 数据来源论文：Zheng et al., *Scientific Data* 8, 244 (2021)，
     https://www.nature.com/articles/s41597-021-01023-5
3. 公开镜像（结构参考）：GitHub `common2016/CHNIO`（数据经脱敏，仅表结构可用，
   **数值必须使用官方原表**）。

## 文件格式（io2017_42sector.csv，UTF-8-SIG）

```
部门名,农林牧渔产品和服务,煤炭采选产品,...,公共管理社会保障和社会组织,总产出(万元),进口(万元)
农林牧渔产品和服务,<Z11>,<Z12>,...,<Z1,42>,<X1>,<M1>
...
公共管理社会保障和社会组织,<Z42,1>,...,<Z42,42>,<X42>,<M42>
```

- Z[i,j]：部门 i 产品被部门 j 中间使用的金额（万元，当年生产者价格）
- X[i]：部门 i 总产出（万元）；M[i]：部门 i 进口（万元，可选）
- 引擎自动做：列归一 A[i,j]=Z[i,j]/X[j] → 进口比例国内化修正 → Leontief 逆 → f=g(I-A)⁻¹

## 42 部门直接排放强度 g（kgCO2e/万元产出）

来源：CEADs 分行业 CO2 排放清单（按 42 部门对齐）。保存为 `g_2017.csv`：
`部门名,kgco2e_per_wan`（42 行）。未提供时，`run_eiolca_42` 只输出矩阵与乘数诊断，
不输出排放量（避免用合成参数冒充官方结果）。
